# Architecture decision records

ADRs capture durable technical/product choices and their tradeoffs.

1. Copy `0000-template.md` to the next zero-padded number and a short slug, for example `0001-wpf-and-hwndhost.md`.
2. Set status to Proposed and link the issue/PR.
3. Record the context, decision, alternatives, consequences, and validation.
4. After acceptance, do not rewrite history. Add a new ADR that supersedes the old one.

The implementation plan currently records initial proposed decisions. Create formal ADRs as those decisions are approved during Phase 0.
